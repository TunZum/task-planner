О проекте
Планировщик задач "TaskMaster"

Учебный проект для освоения веб-разработки на ASP.NET Core.

Технологии:
  • Backend: ASP.NET Core Web API, Entity Framework Core
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
  • База данных: SQL Server LocalDB
  • Инструменты: Visual Studio 2022, VS Code, Git, GitHub
Цель проекта: Освоить полный цикл разработки CRUD-приложения.
